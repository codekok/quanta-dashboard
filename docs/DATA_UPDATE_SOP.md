# 資料更新 SOP

## 1. 接收新資料

- 保留原始附件，不直接覆寫。
- 確認資料屬於廣達《游於智》計畫或廣達游智盃。
- 記錄資料來源、涵蓋期間與本次預期新增內容。

## 2. 更新前比對

先列出：

- 新增紀錄
- 既有紀錄修正
- 同屆同校重複
- 跨屆疑似同校異名
- 同名但可能不同校
- 縣市、行政區或海外地區異常

任何會改變學校識別或合併結果的模糊項目，都要先請使用者確認。

## 3. 寫入與正規化

- 游智盃資料：`public/data/competition.json`
- 游於智資料：`public/data/participation.json`
- 覆蓋率分母：`public/data/denominators.json`
- 校名規則：`scripts/normalize-competition-data.mjs`

執行：

```bash
npm run data:normalize
npm run data:audit
```

## 4. 驗收

至少核對：

- 不重複學校數
- 學校參與校次
- 參與地區數
- 各屆學校數與校次
- 同屆同校是否重複
- 大學附設實驗小學、國小、國民中小學的顯示規則
- 臺南同名學校與海外學校
- 搜尋、篩選、分頁、跨屆歷程及得獎標記
- 桌機及手機閱讀與操作

## 5. 發布

- 先回報數字變化、原因與異常處理結果。
- 提供使用者檢查版本。
- 未取得「同意發布」前，不發布或更新正式網站。

## 6. 更新紀錄

每次更新在工作摘要中留下：日期、資料來源、新增／修正／合併筆數、統計前後差異、例外校名及發布狀態。
