# 廣達游智盃校名統一規則

## 顯示名稱

| 原始名稱類型 | 網站顯示方式 | 範例 |
| --- | --- | --- |
| 國民小學 | 縮寫為「國小」 | 光復國民小學 → 光復國小 |
| 大學附設實驗國民小學／國小 | 統一為「附設實驗小學」 | 國立臺南大學附設實驗國小 → 國立臺南大學附設實驗小學 |
| 原名含「小學」 | 保留「小學」 | 私立復興小學 → 私立復興小學 |
| 原名含「小學部」 | 保留「小學部」 | 私立靜心高級中學國小部不得因此改成國小；正式名稱另依已確認對照表處理 |
| 國中小 | 統一為「國民中小學」 | 新港國中小 → 新港國民中小學 |

目前已確認使用「附設實驗小學」的學校：

- 國立嘉義大學附設實驗小學
- 國立東華大學附設實驗小學
- 國立臺北教育大學附設實驗小學
- 國立臺南大學附設實驗小學
- 臺北市立大學附設實驗小學

## 校名中保留的地區

- 一般學校不顯示縣市前綴。
- 大學附設學校保留完整正式名稱。
- 同縣市內有同名學校時，保留行政區：
  - 東區博愛國小／永康區博愛國小
  - 東區勝利國小／永康區勝利國小

## 學校識別與合併

- `schoolKey` 是跨屆識別鍵，不等於網站顯示名稱。
- 同一屆、同一 `schoolKey` 合併為一筆，得獎狀態取聯集。
- 同名學校若縣市或行政區不同，必須分開。
- 簡稱、舊名或正式全名是否為同校，必須有既定對照或由使用者確認。
- 不可只用字串取代後的顯示名稱判斷是否為同一所學校。

## 特殊地區

- 吉隆坡臺灣學校：`海外－馬來西亞`
